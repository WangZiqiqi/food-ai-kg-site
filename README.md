# CLEAR Evidence Graph — Interactive Demo

Static, browser-only explorer for the evidence graph built by **CLEAR** (Claim-Level Evidence graph with Agentic Refinement and Retrieval).

The demo renders the frozen 850-record claim-level graph used in the manuscript:

> *CLEAR: A Claim-Level Biomedical Evidence Graph Framework with Agentic Refinement and Provenance-Aware Retrieval*

Search for a food, strain, or health outcome to render a focused local subgraph around it, inspect claim nodes with their effect direction and source PMIDs, and follow evidence links across hops. The full graph is indexed but not drawn by default — exploration starts from a chosen center entity.

Companion code and reproducibility package: the CLEAR repository (extraction, agentic refinement, and read-only retrieval).
